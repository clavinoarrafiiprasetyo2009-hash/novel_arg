# 👾 STASIUN_KESEMPATAN_KEDUA // Minecraft ARG Vault & Novel Hub

Website interaktif bertema **Dark Retro-Mystery & Analog Horror** yang menyajikan naskah lengkap novel misteri psikologis *"Stasiun Kesempatan Kedua"* serta bedah komprehensif **4 Pilar Psikologi Manusia** dalam Alternate Reality Games (ARG) Minecraft.

---

## 🌟 Fitur Utama

- **📖 Novel Lengkap "Stasiun Kesempatan Kedua"**:
  - *Bab 1: Stasiun Kabut di Pukul 03:00*
  - *Bab 2: Gerbong Nomor Tiga & Anomali Blok Kayu*
  - *Bab 3: Bayangan di Ujung Peron Seberang*
  - *Bab 4: Pertukaran Ingatan & Tiket Keberangkatan*
  - *Epilog: Sinyal Terakhir di Disc 11*
- **🧠 4 Bedah Analisis ARG Original**:
  - *Pilar 1: KELUARGA* — Kehangatan Rumah yang Terancam & Dorongan Melindungi.
  - *Pilar 2: SAHABAT* — Nostalgia Server Multiplayer 2011 & Duka Jejak Digital yang Hilang.
  - *Pilar 3: PENDAMPING* — Penjaga di Stasiun Waktu Berhenti (03:00) & Ruang Liminal.
  - *Pilar 4: DIRI SENDIRI* — Isolasi Singleplayer & Konfrontasi Paranoia Batin (Herobrine).
- **➕ Upload & Publikasi ARG Baru**:
  - Fitur publikasi karya ARG atau novel buatan pengguna secara dinamis dan tersimpan permanen di `localStorage`.
- **🎨 Customizer Kenyamanan Baca**:
  - Pilihan tipografi (*Serif*, *Sans*, *Mono*) dan ukuran teks (*A-*, *A*, *A+*).
- **⚡ Zero Server Dependency**:
  - 100% Client-side (HTML5, Tailwind CSS CDN, Lucide Icons, Vanilla JavaScript).

---

## 🚀 Cara Menjalankan

Tidak memerlukan instalasi server atau dependency `npm`. Cukup buka file:

```bash
# Buka langsung file index.html di browser favorit Anda
index.html
```

Atau menggunakan Live Server di VS Code / browser apa saja.
